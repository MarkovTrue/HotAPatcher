# HotaPatcher

Два патча для Heroes 3: Horn of the Abyss, каждый включается своей галочкой.

**Убрать окно «Турнирные правила»** – HD-мод показывает его при каждом нажатии «Начать».

**Запоминать настройки новой игры** – выбранные город, герой и бонус подставятся на следующей случайной карте, если там стоит «Случайно». Настройки сохраняются в момент старта карты.

![Окно патчера](Docs/Preview.png)

## Зачем

Официальный FAQ HotA не рекомендует турнирные правила в одиночной игре. Но в HD mod 5.7 плагин `HW_HOTA.dll` грузится безусловно: чекбокс из лаунчера убрали, ini-настройки нет, а без плагина игра не запускается.

## Как пользоваться

1. Закрыть игру.
2. Запустить `Release\HotaPatcher.exe`.
3. Путь к игре подставится сам из реестра. Если нет – кнопка «Обзор...».
4. Отметить нужные патчи и нажать «Применить».

Галочки показывают, что установлено сейчас: отмеченный патч будет наложен, снятый – откачен. Оригиналы файлов сохраняются рядом с расширением `.bak`. Когда оба патча сняты, файлы игры снова оригинальные, и копии удаляются.

## После обновления HD-мода

Обновление перезаписывает `HD_HOTA.dll`, и окно возвращается – просто запустить патчер ещё раз. Место в коде ищется по сигнатуре, а не по фиксированному смещению, поэтому смена версии мода патчу не мешает. Если сигнатура не найдена или найдена не один раз, патчер откажется работать и сообщит об этом, а не испортит файл.

Подробности реализации – в [Docs/Внутреннее устройство.md](Docs/Внутреннее%20устройство.md).

## Проверено на

HotA 1.8.0 + HD mod 5.7 R33, AutoIt 3.3.18.
